# ファイルを並べて開く

エクスプローラーや変更一覧からファイルを選ぶと、中央の編集領域にタブが追加されます。画像も同じ操作で開けます。

1. 比較したいファイルを2つ開きます。
2. 「左右に分割」または「上下に分割」を押します。
3. 境界線をドラッグして表示の比率を調整します。ダブルクリックで半分に戻ります。

タブの「⇄」で別グループへ移動できます。分割後は、使いたいグループをクリックしてから次のファイルを開きます。「分割なし」に戻してもタブと編集内容は保持されます。

画像は「全体表示」と50〜400%の倍率を選べます。テキストは選択中のグループのファイルを Ctrl+S（MacではCommand+S）で保存します。Ctrl+\ で左右分割、Ctrl+Wで選択中のタブを閉じます。

「タスクに戻る」で編集領域を隠しても、タブと未保存内容は残ります。上部の「開いているファイル」から戻れます。未保存のタブを閉じる際は破棄確認が表示されます。アプリの再起動・ページの再読み込み・入れ直しのあとも、開いていたタブ・分割・自由配置の並べ方と、保存していなかった書きかけが戻ります（この端末に保存。書きかけは 30 ファイル・1 つ 100 万文字まで）。書きかけを取ったあとにファイルが変わっていた時は自動では戻さず、「書きかけを戻す」「捨てる」を選べます。消したタスクのタブは閉じます。

作業中のタスクと外部タスクのファイルは引き続き閲覧専用です。

「自由に配置」では普通のウィンドウのように操作できます。タイトルバーをドラッグして移動、辺・四隅をドラッグして縦横の大きさを変更、上部の丸いハンドルをドラッグして回転します。Shiftを押しながら回すと15°刻みになり、Escapeでドラッグを取り消せます。タイトルバーのダブルクリックまたは□で最大化・復元します。クリックしたウィンドウは手前に出ます。

余白のドラッグ（またはマウス中ボタンのドラッグ）でデスクを移動、余白のホイールでマウス位置を中心に拡大縮小できます。ウィンドウ上ではCtrl＋ホイールでデスクを拡大縮小し、通常のホイールはファイル内のスクロールに使います。「整列」で重なりと回転をリセットし、全体が見える倍率にします。通常表示との切替でも配置と未保存の内容は保持し、アプリを再起動しても元の配置に戻ります。

エクスプローラーは選択中のファイルの所属に切り替わり、そのファイルを強調します。「非表示の設定」は名前または相対パスを1行ずつ登録でき、`.*` はドットから始まる項目を隠します。設定は端末に保存します。

検証: Viteを127.0.0.1:5179で起動し、`node apps/web/editor-check.mjs`を実行します。APIをモックし、実ファイルには書き込みません。

### 水中の見た目と行動

- `public/aquarium/` の水景・魚PNGはこのタスク用に画像生成。背景は岩・流木・水草・砂の写実的な水景。魚は3種類の透明素材を分割描画して尾びれを変形。
- `aquarium-simulation.ts` は毎回ランダムな初期値から30匹を動かす。群れの目標、個体の離脱・目標変更・近距離回避、速度と奥行きの変化を持つ。同じseedならテストで再現可能。
- 画面サイズの背景／前景Canvasを使用。近い魚や泡はガラスの枠を横切り、文書の中央は前景から除外。ファイル枠に透過・屈折・水色の反射を適用し、文字領域は濃い水色で読みやすさを保つ。
- 明示的な再生／静止はOS設定より優先。一時停止で魚の配置や時間をリセットしない。外部配信画像には依存しない。
- 検証: 5分相当のシミュレーション、異なるseed、停止・長いフレーム間隔、既存の幾何テスト、画像の読み込み、OS設定による停止と明示的再生、ガラス表示と編集操作、レスポンシブ表示。


### 2026-09-12 背景の作り込み

- 魚の向きの切り替えは、頭から先に向きを変えて尾が遅れてついてくる「体のひねり」で描く（`facing` と遅れて追いかける `tail`、手前へ回るか奥へ回るかの `turn`）。真横を向いた瞬間も体の厚み分は残す。
- 水は WebGL（`aquarium-water.ts`）で描く。写真の緑の部分（葉・茎・苔）をマスクにして水草だけをゆっくり揺らし、上部の水面帯をゆらめかせて光らせ、左上からの光の筋を動かす。WebGL が使えない端末では従来どおり静止写真＋屈折帯で描く。 頂点側とフラグメント側で同じ uniform を持たない（精度指定が食い違うとリンクに失敗する）。後片付けでコンテキストは失わせない（同じ canvas で effect が再実行されると失ったままになる）。WebGL に落ちた時は console に日本語で警告を出し、`.aquarium-canvas` の `data-water` が `gpu` か `2d` かで分かる。
- 星空・森・電気図面・設計図は動く背景（`desk-scenes.ts`、`DeskScene.tsx`）。星のまたたきと流れ星、木立の層の視差と光の筋・蛍・落ち葉・霧、基板上を走る信号と点滅する LED、図面が線から描き上がっていく様子。作業机（木目と机上ランプ）・方眼紙（紙の繊維）・黒板（消し跡・チョークの粉・チョーク受け）は描き込んだ静止画。ドットと無地は従来どおり CSS。
- 動く背景の視差は、デスク上での表示位置（−1〜1 に正規化）から求めるため、デスクの倍率に依存しない。
- 検証: 幾何テスト4件、水槽のシミュレーション・マスクのテスト3件、画面テスト（文字の大きさ変更で枠が変わらないこと、7 種の背景が描かれ動く背景は再生／静止できること、スクリーンショット `docs/screenshots/desk-*.png`）。


## 2026-09-12 エディタの道具（VS Code でよく使う機能）

- ファイル名で開く（Ctrl+P、またはエクスプローラーの「名前で開く」）: 名前の一部・飛び飛びの文字・空白区切りの複数語で絞り込み、↑↓ と Enter で開く。一覧は git があれば .gitignore に従い、node_modules などの重いフォルダは入れない（サーバー `search.ts` の `listAllFiles`）。
- プロジェクト全体から探す（Ctrl+Shift+F、または左端の「検索」）: 文字をそのまま探す（正規表現ではない）。大文字・小文字は既定で区別しない。1000 件・4 秒で打ち切る。結果を押すとその行を真ん中に出して、見つかった文字を選ぶ。
- 変わった行の印: 行番号の右に 緑＝足した行、青＝変えた行、赤い三角＝その下で行を消した。比べる相手は最後の記録（コミット）、別の作業場所のタスクは元のプロジェクト。右端のスクロールバーにも同じ色が出る。上の「変わった所 N か所 ↓」で次の変わった所へ。
- Markdown（.md）は最初「読みやすく表示」で開く。見出し・表・チェック欄・画像を整え、文書に書かれた HTML は消毒する（スクリプトは動かない）。プロジェクト内へのリンクはそのファイルをタブで開き、外のページはいつものブラウザで開く。「編集」で文字に切り替え。
- エディタの右クリックメニューや検索窓などの文字を日本語にした（Monaco 同梱の日本語訳を先に読み込む）。
- 検証: 型チェック、サーバーのテスト 4 件（一覧と .gitignore、検索の行・位置、変わった行の印、差分の見出しの読み取り）、画面側の計算テスト 2 件、画面テスト `node apps/web/editor-tools-check.mjs`（Vite を 127.0.0.1:5179 で。別の番号なら `TOWER_TEST_URL`）。既存の `editor-check.mjs` も通過。
