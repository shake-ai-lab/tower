- 権限と操作の再試験は、更新したインストール済みTower（4800番）の実React画面・実API・実モデルで行った。APIやモデルの応答を置き換える検証ではない。

- 作品切り替え時に古いダイアログを閉じ、読込・保存・テンプレート適用・参照画像の応答が移動先へ混入する問題を修正。開始時の作品・ページ・世代を固定し、書込前と応答反映前の両方で確認する。
- 反復UI試験の初期化失敗を診断し、Windowsの接続エラー10055を記録。テスト用WSGIサーバーで接続を再利用し、通信・コンソール・失敗画面の診断と終了確認を追加した。アプリの機能、期待値、待ち時間は緩和していない。

## Tower本体の修正

- 設定・新規タスク・既存タスクでCodexの権限を選択できるようにし、既定値を保存する。実行途中の変更は次の新しい手番から反映する。[先行の権限検証](../codex-permissions/report.md)
- 本文とコマンドの途中出力を200ms単位で表示。容量を制限し、完了・停止・失敗・再起動時に消去する。末尾を読んでいる場合だけスクロールを追従させる。
- 会話の再開失敗を新規会話へ黙って切り替えず、元の会話IDを保持して理由を表示する。
- MCP入力フォームを架空の値で受諾する処理を廃止。未対応のフォームは理由を表示して辞退し、URL手続きはフルアクセスでも人の完了確認を待つ。
- WindowsのCodex起動に `allow_login_shell=false` を指定し、プロファイルとの衝突を回避。未設定の場合だけPythonの標準入出力をUTF-8にする。利用者の設定・プロファイル・既存ファイルの文字コードは変更しない。
- Windowsの読取時の文字コード指定と、文字化けした出力を推測せず再確認する手順をCodexへの指示に追加。

`allow_login_shell` は [公式設定](https://learn.chatgpt.com/docs/config-file/config-reference) を参照し、実バイナリの `config/read` でも受理を確認した。CodexのPowerShell初期化は [公式実装](https://github.com/openai/codex/blob/main/codex-rs/shell-command/src/powershell.rs#L10-L29) も調べ、実環境で別途検証した。

## 確認できた範囲と制約

- ファイル調査・編集・コマンド・テスト・ブラウザー操作・追加指示・権限の拒否/許可・停止/再開を実際に通した。外部アカウントへのログインや全プラグインの機能は網羅していない。
- 外部MCPの入力フォームは未対応。未入力値を勝手に送らないことを優先し、辞退する。同期質問は回帰試験で確認したが、質問やフォームの全形式が同等とは主張しない。
- 制限付きWindows PowerShellの日本語標準出力にはCodex本体側の制約が残る。PythonのUTF-8出力は実機で改善を確認。コードページ変更後に新しいPowerShellを起動する方法も、ConstrainedLanguageを維持した実モデルで日本語出力に成功したが、CLIXMLの進捗出力が残る。複雑なラッパーを全コマンドへ強制する実装は採用していない。[切分け前](encoding-before.json)、[Python補正後](encoding-after.json)、[新しいPowerShellでの確認](encoding-new-shell.json)
- 元から1件あるタグ照合テストのスキップは、照合キャッシュ不足によるもの。失敗の削除や成功への読み替えはしていない。
