# Codex の権限設定と承認処理の修正

2026-09-13。対象は権限設定の欠落と、その設定を実行に反映する経路。

修正内容:

- 新規タスクと既存タスクの両方で Codex の権限を選択できるようにした。既存タスクの変更を拒否していた Manager の Claude 専用ガードも修正した。
- 設定画面に Codex の既定権限を追加。新しい Codex タスクだけに適用し、個別の選択を優先する。Claude の選択とは状態を分離した。
- 「ネットワーク無し」という実装と異なる固定説明を撤去し、4つの権限ごとに書き込み範囲・ネット接続・確認の説明を表示した。
- 設定の読み込みに失敗した場合は起動を止め、再試行を提供する。遅い応答で利用者の選択を上書きしない。
- Codex が確認を求めたコマンドを Tower 独自の読み取り判定で自動承認する処理を除去した。`git diff --output`、`rg --pre`、PowerShell の式などで承認を迂回できたため。
- 作業途中の設定変更は次の新しい手番から反映。実行中の手番の承認は、その手番に渡した権限で判定し、設定変更だけで承認待ちを解除しない。

現在の応答への追加指示は `turn/steer` であり、新しい手番ではない。公式にも手番の設定を上書きできないと記載されている。この制約と、すぐ反映するには停止してから指示を送る手順を画面に表示した。[OpenAI の App Server 文書](https://learn.chatgpt.com/docs/app-server#steer-an-active-turn)
