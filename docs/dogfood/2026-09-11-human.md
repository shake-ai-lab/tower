## 直したもの（コミット参照）
1. 報告の「変更ファイル」の注釈（「README.md（新規作成）」）で件数が 1 多くなる → 注釈を落としてから合流
2. `__pycache__` / バイナリが「追加」に出る → 未追跡の生成物とバイナリを除外
3. 年表のツール結果を日本語に（読みました（N 行）/ 書き換えました / 書きました / 報告を書きました）
4. 編集の許可カードを「変更前 / 変更後」の 2 段に
5. 差分の git ヘッダ行を非表示、`@@` は区切り線
6. 報告文中の `コード` を code 表示
7. ヘッダの「接続中」を、切れた時だけ出す赤字に
8. 「終わったもの N 件を隠す」（消さない）
9. 比べる案を片付けた後の文言

## 直していないこと
- 使った量がセッション集計なので、削除すると減る
- サーバー再起動で全部「停止」になる（既知）。「隠す」がオンだと一覧から消えるが件数は出る
- 外部セッションの「今やってること」が英語（Claude Code 側の説明文）
