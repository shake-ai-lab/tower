# AI利用者役の自由探索

目的: notes.txtを開き、本文をマウスでクリックしてからHelloを入力してください。Ctrl+Sで保存し、保存表示と入力した文字を画面で確認してください。迷った点を記録し、達成したらfinishしてください。

モデル: haiku / 5操作 / 終了判断

以下はAIの観察候補です。確定した不具合とする前に再現確認してください。


## 操作 1

左のエクスプローラーにある notes.txt をクリックしてファイルを開く。操作対象番号18。

click / 対象 18 / 

- notes.txt がエクスプローラーに表示されている（操作対象番号18）

[操作前の画面](1.png) / [画面の読み取り](1.yml)

## 操作 2

notes.txtのエディター領域（操作対象番号32）をクリックして、フォーカスを明確にします。既にフォーカスがあるかもしれませんが、目的で「本文をマウスでクリックしてから」と明記されているので、クリック操作を実行します。

click / 対象 32 / 

- エディター領域が表示されている（操作対象番号32）
- 現在のコンテンツ: 1.買い物メモ 2.apple と banana を買う 3.（空白）
- フォーカスがあると表示されているが、マウスクリックで確実にフォーカスを取得する

[操作前の画面](2.png) / [画面の読み取り](2.yml)

## 操作 3

エディター領域にフォーカスがあるので、型入力アクションで "Hello" を入力します。target=-1 は「現在の入力先」を指すため、既にフォーカスのあるエディターへ直接入力できます。

type / 対象 -1 / Hello

- エディター領域にフォーカスがある状態で type アクションを実行
- 操作対象番号32のテキストボックスへの入力

[操作前の画面](3.png) / [画面の読み取り](3.yml)

## 操作 4

Helloが入力済みなので、Ctrl+Sキープレスで保存を実行。Press操作でControl+sを送信。

press / 対象 -1 / Control+s

- エディター内にHelloが入力されている（Line 1: 買い物メモ Hello）
- タブに未保存を示す ●記号がある
- 保存（Ctrl+S）ボタンが画面に表示されている

[操作前の画面](4.png) / [画面の読み取り](4.yml)

## 操作 5

notes.txtを開き、マウスでクリック、Helloを入力、Ctrl+Sで保存というすべての操作が完了しました。保存表示（✓保存しました 17:58）と入力された文字（Line 1: 買い物メモ Hello）が画面に確認されています。迷った点はなく、目的達成できたのでfinishアクションを実行します。

finish / 対象 -1 / 

- 目的達成: notes.txtを開く・マウスでクリック・Helloを入力・Ctrl+Sで保存が完了
- 保存表示: ✓保存しました 17:58 と画面に表示されている
- 入力確認: Line 1に『買い物メモ Hello』と正確に表示されている
- 迷った点: なし。操作は直感的に進行した
