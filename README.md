# Tower — AIエージェント管制塔

複数プロジェクト × 複数エージェント（Claude Code、将来 Codex）を **一画面で指揮する** 個人用ツール。
コードを読まずに「指示を出す・許可する・質問に答える・結果を判断する」だけで開発を進めるためのUI。

## 起動

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開く。

- サーバー: http://127.0.0.1:4800（REST + WebSocket）
- 画面: Vite dev server（`/api` と `/ws` をサーバーへプロキシ）

Claude Code に手元の `claude` でログイン済みであること（Max/Pro の定額ログインで動く。API キー不要）。

## 使い方

1. **＋ 新しいタスク**（キー `n`）→ プロジェクトを選んで、指示を書いて **起動**
   - 「許可」で方針を選べる: **編集は自動**（既定。ファイル編集は自動、コマンドだけ確認）/ **毎回確認** / **おまかせ**（AIが安全そうなものを自動承認）
2. エージェントが許可を求めたり質問したりすると **判断インボックス** に並ぶ → 許可 / 以後も許可 / 拒否 / 回答
3. 作業が一区切りつくと **報告カード**（依頼 / 結果 / やったこと / 変更ファイル / 判断が必要 / 次の一手）が出る
   - 同時に Tower がプロジェクトのテスト（`npm test` など）を自分で走らせ、**裏取りOK / NG** を報告の横に出す。エージェントが「完了」と言っているのにテストが落ちていれば警告する
   - 起動直後にも同じテストを走らせておくので、「修正前: 失敗 2 件 → 修正後: 全部成功」のように **直った / 壊れた / まだ直っていない** が一目で分かる
   - 報告に決まった書式が無かった時は、Tower が AI で読みやすく整形する（カードに **Tower が整形** と付く。原文は「原文を見る」）
4. カードを開いて **差分を見る**、**追加の指示** を送る（Ctrl+Enter）
5. サーバーを再起動して止まったセッションも、指示を送れば **続きから再開** する

### 画面からファイルを直す

「変更されたファイル」を開くと、各ファイルに **直す** ボタンがある。押すとエディタ（Monaco）で開き、**保存（Ctrl+S）** でそのまま書き込む。

- 保存すると、次に指示を送る時に「このファイルを手で直した」と AI に自動で伝わる（指示の末尾に補足が付く）
- テストがあれば保存後に裏取りも走る
- エージェントが作業中は押せない（報告が来るか、停止してから）

### 同じプロジェクトに複数のタスクを同時に任せる（別の作業場所）

「新しいタスク」の **別の作業場所で動かす** をオンにすると、プロジェクトのコピー（git worktree）と専用ブランチで作業する。同じプロジェクトで他のタスクが動いている時は自動でオンになる。

- 元のフォルダは変わらない。カードに **分離** の印が付き、「差分を見る」は元のプロジェクトとの比較になる
- 報告が来たら **元のプロジェクトに取り込む** を押す（自動でコミット → merge）。何度でも押せる
- 競合したら取り込みは中止され、そのセッションに「元のブランチの変更を取り込んで競合を直して」と指示すれば AI が直す
- セッションを削除するとコピーとブランチも消える（取り込んでいない変更は失われる）
- git 管理で、コミットが1つ以上あるプロジェクトのみ。`node_modules` は元のプロジェクトのものを共有する

ブラウザの「通知を有効にする」を押しておくと、許可待ち・質問が来た時にデスクトップ通知が出る。

## VS Code 拡張 / ターミナルのセッションも表示する

右上の **VS Code 連携** をオンにすると、Claude Code の hooks を `~/.claude/settings.json` に書き込み（バックアップあり・他の設定はそのまま）、Tower の外で動いているセッションもカードに出ます。

- 観測: 起動 / 指示 / 今やってること / 報告 / 終了。カードに「VS Code」「ターミナル」の印が付く
- **許可も Tower で答える** をオンにすると、外のセッションの許可要求もインボックスに出て、ここで許可 / 拒否できる。設定の `bridgeWaitSeconds`（既定 90 秒）以内に答えなければ元の画面の許可ダイアログに戻る
- 外のセッションに Tower から指示を送ると、Tower が会話を引き継いで続きを動かす（元の画面で同時に動かさないこと）
- 外のセッションの報告は書式が無いので、Tower が AI（Haiku）で整形して報告カードにする
- 最後の動きから 24 時間（設定 `externalKeepHours`）たった外のセッションは一覧から自動で消える。また動けば戻る

## Codex（OpenAI）も使う

「新しいタスク」で **Codex** を選べる。Codex の実行ファイルは同梱されているので、一度だけログインする:

```bash
npx codex login     # ChatGPT アカウントでログイン（または OPENAI_API_KEY を環境変数に）
```

Claude との違い: Codex（`codex exec`）は作業中に許可を都度聞けないので、**作業フォルダ内だけ書き込み可・ネットワーク無しの砂場**で動かす。報告カード・裏取り・差分表示・再開は同じように使える。

## 使い込んで良くする（ドッグフーディング）

```bash
npm run dogfood                     # 利用者役AIが7本のシナリオを並列で投げ、許可や質問に答え、報告を採点する
npm run dogfood -- --only todo-fix  # 一部だけ
```

結果は `docs/dogfood/<runId>.md`。「分かりやすさ」「達成」「報告と検証の食い違い」「アプリへの改善提案」が並ぶ。

## 設定

`~/.tower/config.json`（初回起動時に自動生成）

```json
{
  "host": "127.0.0.1",
  "port": 4800,
  "projectRoots": ["C:\\Users\\you\\project"]
}
```

- `projectRoots`: この下のフォルダを「プロジェクト」として一覧に出す
- `host` を `0.0.0.0` にすると同じWi-Fiのスマホからも開ける（認証は無いので自宅LAN限定で）
- `autoVerify`: 報告のたびにテストを走らせる裏取り（既定 true）。プロジェクト側で `.tower.json` に `{"verify": "npm run check"}` と書けばコマンドを指定、`{"verify": null}` で無効
- `reformatReports`: 書式の無い報告を AI で整形する（既定 true）
- `externalKeepHours`: VS Code / ターミナルのセッションを何時間動きが無ければ一覧から消すか（既定 24。0 で消さない）

履歴は `~/.tower/tower.db`（SQLite）。

## 構成

```
apps/server     Node + Hono + ws。Claude Agent SDK でセッションを動かし、生イベントを翻訳して配信
apps/web        React + Vite + Tailwind。フリート画面 / 判断インボックス / セッション詳細
packages/shared フロントとサーバーの契約（型）
docs/DESIGN.md  設計判断とロードマップ
```

## 注意

- 手元の Claude Code ログイン（claude.ai）で動くのは **自分用ツールとして使う場合**。他人に配布する製品にするなら API キー方式に切り替える必要がある（Agent SDK の規約）。
- サーバーを再起動すると動いていたセッションは「停止」になるが、指示を送れば続きから再開できる（許可待ちの途中だったものは、その操作からやり直しになる）。
